# Cloud Infrastructure Components

## Checkpoint 3 – Identify Cloud Infrastructure Components

This activity identifies the main cloud infrastructure components in the KillerCoda Linux environment: compute, storage, networking, and the operating system.

## 1. Compute Resources

**Example:** CPU and CPU cores

**Purpose:** Provides processing power for running applications, commands, and services.

**Importance in Cloud Computing:** Allows applications to perform tasks and can be scaled depending on the workload.

**Relation to KillerCoda:** The server provides CPU resources for Linux processes. CPU information can be checked using `lscpu` and `nproc`.

## 2. Storage Resources

**Example:** Disk storage and file systems

**Purpose:** Stores the operating system, applications, files, and data.

**Importance in Cloud Computing:** Provides reliable storage and can be expanded when more space is needed.

**Relation to KillerCoda:** The Linux server uses disk storage for system files and data. Storage usage can be checked using `df -h`.

## 3. Networking Resources

**Example:** IP address and network interface

**Purpose:** Allows the server to communicate with other systems and cloud services.

**Importance in Cloud Computing:** Connects cloud resources and allows users to access services.

**Relation to KillerCoda:** The server has a network connection and IP address. The IP address can be checked using `hostname -I`.

## 4. Operating System

**Example:** Ubuntu 24.04.4 LTS

**Purpose:** Manages hardware and software resources and provides an environment for applications.

**Importance in Cloud Computing:** Helps manage server resources and run applications and services.

**Relation to KillerCoda:** KillerCoda provides an Ubuntu 24.04.4 LTS environment for practicing Linux and cloud-related tasks.
