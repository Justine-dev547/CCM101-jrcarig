# Cloud Provider Comparison

## Checkpoint 4 – Research the Major Cloud Providers

This activity compares three major cloud providers: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Cloud Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| **Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **Networking** | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| **IAM** | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

AWS provides EC2 for computing, S3 for storage, VPC for networking, and IAM for access management. Azure offers Virtual Machines, Blob Storage, Virtual Network, and Entra ID/RBAC. Google Cloud provides Compute Engine, Cloud Storage, VPC, and Cloud IAM.

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

**AWS** offers a very wide range of cloud services, including computing, storage, databases, networking, security, AI, and analytics.

### 2. Which platform is recommended for organizations using Microsoft products?

**Microsoft Azure** is a good choice because it integrates well with Microsoft products and services.

### 3. Which platform is known for AI, ML, and Kubernetes?

**Google Cloud** is well known for its AI and machine learning services and its strong Kubernetes support.

### 4. What similarities did you observe?

All three providers offer **compute, storage, networking, and IAM services**. Their names and features may differ, but they provide similar core cloud infrastructure.
