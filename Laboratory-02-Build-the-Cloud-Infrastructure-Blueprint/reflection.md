# Mission Reflection

This laboratory activity helped me understand the basic parts of cloud infrastructure and how they work together. I learned that **compute resources** are important because they provide the processing power needed to run applications, services, and tasks.

I also learned how Linux supports cloud computing. Using the KillerCoda Playground, I practiced Linux commands to check the operating system, CPU, RAM, storage, file systems, hostname, and IP address. This helped me understand how cloud servers are managed and monitored.

Technical documentation is also important because it keeps system information organized. It helps developers and engineers understand the infrastructure, find problems, and maintain the system more easily.

Throughout the activity, I learned about Linux commands, cloud infrastructure, and the services offered by AWS, Azure, and Google Cloud. I also improved my skills in **Markdown, technical documentation, cloud research, and GitHub**.

Overall, this laboratory gave me practical experience with Linux and cloud computing. It also helped improve my GitHub portfolio by adding organized reports, screenshots, comparisons, and reflections.
