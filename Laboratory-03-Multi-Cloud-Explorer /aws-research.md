## Brief Overview

Amazon Web Services (AWS) is a public cloud platform operated by Amazon. AWS launched in 2006 and provides services covering compute, storage, networking, databases, security, analytics, containers, and artificial intelligence.

## Global Infrastructure

AWS organizes its infrastructure into geographic Regions and Availability Zones. Each Region contains multiple isolated Availability Zones that can be used to design highly available applications.

AWS currently reports 39 geographic Regions and 124 Availability Zones on its global infrastructure page. This infrastructure allows organizations to deploy applications closer to customers and improve availability.

## Cloud Management Console

The AWS Management Console is a web-based interface for managing AWS resources. Users can search for services, create resources, monitor infrastructure, manage accounts, and view billing information.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable virtual servers for running applications.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, backups, application data, and other objects.

### 3. Amazon VPC

Amazon Virtual Private Cloud provides networking capabilities that allow organizations to create isolated networks for AWS resources.

### 4. AWS IAM

AWS Identity and Access Management controls access to AWS resources through users, roles, and permissions.

## Three Advantages

1. Very broad selection of cloud services.
2. Large global infrastructure supporting worldwide deployments.
3. Flexible scaling and pricing options for different workloads.

## Typical Enterprise Use Cases

AWS can be used for:

- Web and mobile applications
- Enterprise application hosting
- Backup and disaster recovery
- Data analytics
- Artificial intelligence and machine learning
- Containerized applications
- Global e-commerce platforms
