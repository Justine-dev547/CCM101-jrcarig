## Brief Overview

Microsoft Azure is Microsoft's public cloud computing platform. It provides services for computing, storage, networking, databases, identity, artificial intelligence, analytics, and application development.

Azure launched in 2010 and has developed strong integration with Microsoft's enterprise ecosystem.

## Global Infrastructure

Azure provides a large worldwide infrastructure consisting of geographic regions and data centers. Microsoft's current infrastructure information lists more than 80 Azure regions and more than 500 datacenters.

This geographic coverage allows organizations to deploy services near users and address data residency and latency requirements.

## Cloud Management Console

The Azure portal is a web-based unified management console. It allows administrators and developers to create, configure, monitor, and manage Azure resources through a graphical interface.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provides scalable virtual machines for Windows and Linux workloads.

### 2. Azure Blob Storage

Azure Blob Storage provides scalable object storage for unstructured data.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources and can connect cloud resources with on-premises infrastructure.

### 4. Microsoft Entra ID

Microsoft Entra ID provides cloud-based identity and access management for users, applications, devices, and resources.

## Three Advantages

1. Strong integration with Microsoft technologies.
2. Extensive support for hybrid cloud environments.
3. Broad global infrastructure and enterprise security capabilities.

## Typical Enterprise Use Cases

Azure can be used for:

- Windows Server migration
- Microsoft 365 environments
- Enterprise applications
- Hybrid cloud infrastructure
- Database modernization
- AI and machine learning
- Virtual desktops
- Kubernetes applications
