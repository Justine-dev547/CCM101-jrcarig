## Client A – Startup Company

### Recommendation: AWS

AWS is a strong choice for the startup because it provides a very broad range of services and flexible ways to scale as the company grows. The startup can begin with relatively simple infrastructure and add services as demand increases. AWS also provides services suitable for mobile backends, databases, storage, authentication, monitoring, and serverless applications.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS Lambda
- Amazon Cognito

---

## Client B – University

### Recommendation: Microsoft Azure

Microsoft Azure is the most appropriate choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong Microsoft ecosystem integration and supports hybrid environments. The university can migrate workloads gradually instead of moving everything at once.

### Possible Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure SQL Database
- Azure Virtual Network
- Azure Migrate

---

## Client C – AI Research Company

### Recommendation: Google Cloud

Google Cloud is my recommended platform for this scenario because the company's main requirement is artificial intelligence and high-performance computing. Google Cloud provides AI/ML services such as Vertex AI and infrastructure designed for demanding workloads. The company can combine AI services with scalable compute and storage resources.

### Possible Services

- Vertex AI
- Compute Engine
- Cloud Storage
- Google Kubernetes Engine
- BigQuery

---

## Client D – Global E-Commerce Company

### Recommendation: AWS

AWS is a strong choice for the global e-commerce company because of its broad global infrastructure and extensive scalability options. The company can distribute workloads across regions and Availability Zones and use load balancing and automatic scaling to handle changing traffic. AWS also provides databases, storage, networking, monitoring, and security services needed for an e-commerce architecture.

### Possible Services

- Amazon EC2
- Elastic Load Balancing
- Amazon EC2 Auto Scaling
- Amazon S3
- Amazon Aurora
- Amazon CloudFront

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Broad services and flexible scaling |
| Enterprise Organization | AWS | Large service portfolio and enterprise capabilities |
| Microsoft Environment | Azure | Strong Microsoft ecosystem integration |
| AI / Machine Learning | Google Cloud | Strong AI/ML infrastructure and Vertex AI |
| Kubernetes Deployment | Google Cloud | Strong Kubernetes ecosystem and GKE |
| Global Web Application | AWS | Extensive global infrastructure and scalability |
