## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is generally the strongest choice when the requirement is the broadest overall selection of cloud services. Its portfolio covers compute, storage, networking, databases, security, analytics, containers, AI, and many specialized workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. This is particularly important for organizations using Windows Server, Microsoft 365, Active Directory, SQL Server, and other Microsoft technologies.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in AI, data analytics, and Kubernetes because of Google's AI infrastructure, Vertex AI, and its history with Kubernetes. AWS and Azure also provide strong AI and managed Kubernetes services, so the final choice should depend on the workload and existing environment.

### 4. Which cloud platform would you personally choose and why?

My choice would be **AWS**. I would select it based on factors such as service availability, cost, technical requirements, existing skills, security, scalability, and the type of applications being deployed.
