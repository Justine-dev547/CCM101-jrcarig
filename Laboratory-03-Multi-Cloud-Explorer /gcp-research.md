## Brief Overview

Google Cloud Platform (GCP), now generally called Google Cloud, is Google's public cloud platform. It provides compute, storage, networking, databases, containers, analytics, and artificial intelligence services.

Google App Engine was launched in 2008 and became one of the earliest major Google Cloud services.

## Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. Its infrastructure is designed to provide scalable and reliable connectivity for applications and services around the world.

Google Cloud also operates a large private network connecting its global infrastructure.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources.

## Four Core Services

### 1. Compute Engine

Compute Engine provides configurable virtual machines for running applications and workloads.

### 2. Cloud Storage

Cloud Storage provides scalable object storage using buckets and objects.

### 3. Google Cloud VPC

VPC provides networking for Compute Engine, Google Kubernetes Engine, and other cloud workloads.

### 4. Google Cloud IAM

Cloud IAM controls which users and systems can access Google Cloud resources and what actions they are allowed to perform.

## Three Advantages

1. Strong AI and machine-learning capabilities.
2. Excellent Kubernetes and container ecosystem.
3. Google's global networking infrastructure and data-processing technologies.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Artificial intelligence and machine learning
- Big-data analytics
- Kubernetes applications
- Web applications
- Data warehousing
- Application modernization
- Global-scale services
