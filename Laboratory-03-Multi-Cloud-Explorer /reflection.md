# Mission Reflection

During this laboratory activity, the cloud platform that impressed me the most was **Google Cloud Platform (GCP)** because of its strong capabilities in artificial intelligence, machine learning, data analytics, and Kubernetes. I learned that AWS, Microsoft Azure, and GCP have many similarities because they all provide important cloud services such as virtual machines, object storage, networking, databases, identity management, security, and scalable infrastructure. Although their services have different names and features, they can often perform similar functions for organizations.

I also learned that business requirements are very important when selecting a cloud platform. Factors such as budget, existing technology, security, scalability, location, workload requirements, and technical skills should be considered before making a decision. For example, Azure is suitable for organizations that already use Microsoft products, while GCP is a strong choice for artificial intelligence and machine learning workloads. AWS is useful for organizations that require a wide variety of services and global infrastructure.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. Instead, a consultant must understand the client's needs and recommend a solution that provides the best balance of cost, performance, security, and scalability. My GitHub Cloud Computing Portfolio also improved because I added organized Markdown files, service comparisons, client recommendations, and screenshots as evidence. Overall, this activity helped me improve my technical documentation and research skills while teaching me that successful cloud decisions require both technical knowledge and an understanding of business requirements.
