# Laboratory 05 - Cloud Data Engineer

## Mission Overview

In this laboratory activity, I learned about cloud storage and the three main types of storage: Block Storage, File Storage, and Object Storage. I also deployed a MinIO object storage server using Docker and created a bucket for storing files.

## Objectives

* Understand the differences between Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access the MinIO Web Console.
* Create a storage bucket.
* Upload a sample file to the bucket.
* Document the cloud storage deployment process.

## Tools Used

* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser

## Skills Learned

* Understanding different types of cloud storage
* Using Docker to deploy a cloud service
* Accessing services through ports
* Creating and managing storage buckets
* Uploading objects to cloud storage
* Creating documentation using Markdown
* Using GitHub for cloud computing portfolio documentation
